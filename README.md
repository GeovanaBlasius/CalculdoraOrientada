# Gerador de Tabuada

Exercício inicial em Java que monta a tabuada de um número até o limite escolhido.

**Disciplina:** Programação Orientada a Objetos I  
**Tecnologias:** Java

## Como funciona

- Lê o número da tabuada e até onde ela deve ir
- Se o primeiro valor for maior que o segundo, troca os dois e avisa
- Mostra cada linha no formato `n x i = resultado`

## Como executar

```bash
cd CalculadoraOrientada/src
javac Main.java
java Main
```
